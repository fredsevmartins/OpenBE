# Replicate bioequivalence

Designs 02–11 use replicateBE Method A and Method B. Each has an independent
executable script, source dataset, model comparison, CV estimates, ratio CI,
diagnostic figures and English tutorial in the [design catalog](study-designs.md).

Method B assumes a common residual variance. CVwT is nonestimable in partial
replicates; missing is not zero. Historical expanded limits are computational
illustrations, with a separate GMR constraint, not automatic regulatory ABEL
eligibility. Balaam and extra-reference designs are documented for analysis
and teaching, with warnings against recommending them for new studies.
