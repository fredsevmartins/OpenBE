# Conventional bioequivalence

[The two-period crossover tutorial](tutorials/design_01_2x2_crossover.qmd)
executes both AUClast and Cmax analyses with BE, including nested-subject ANOVA,
geometric LS means, T/R ratio, 90% CI, CV and TOST p-values. Its source dataset
is simulated by BE; it is not observed trial evidence.

The default mathematical interval limits are 0.80–1.25. Containment does not
establish current regulatory applicability. See [statistical models](statistical-methods.md)
and [regulatory framework](regulatory-framework.md).
