# OpenBE

Open-Source Bioequivalence Analysis is an R toolkit for reproducible scientific
research. It wraps established engines, supplies 14 executable design workflows,
and records numerical evidence, provenance and model limitations.

Start with [Getting Started](getting-started.md), the [study design catalog](study-designs.md)
and the [scientific validation report](validation/VALIDATION_REPORT.md).

Conventional and replicate workflows are tested but not comprehensively
independently validated. Custom parallel and Williams workflows are experimental.
All regulatory classifications remain undetermined until current rules and
eligibility are qualified. No Shiny interface, regulatory approval or deployment
of this site is claimed.
